EJERCICIO I 
1. Implementar una pagina web para mostrar un usuario aletorio.
2. Obtener la información del usuario utilizando el api Random User Generator y mostrar sus datos.
3. Agregar un botón para actualizar la información con nuevo usuario.
4. Estilizar la pagina con CSS, debe de ser responsive.
5. Subir el código en un repositorio de Github o GitLab o Bitbucket.
